# Tema Shopify "La Culla della Luna"

Tema Online Store 2.0 per https://laculladellaluna.myshopify.com, colori Muschio.
Controllato con `shopify theme check`: 48 file, nessun errore né avviso.

## Installazione (dal pannello Shopify)
1. Negozio online → Temi → Aggiungi tema → **Carica file .zip** → scegli `la-culla-della-luna-tema-shopify.zip`.
2. Sul tema caricato: **Personalizza** per l'anteprima. Quando va bene: **Pubblica**.
   Il tema attuale resta nella libreria: si può tornare indietro in qualsiasi momento.

## Da impostare una volta
- **Menu** (Negozio online → Navigazione → Menu principale), per esempio:
  Collezione → `/#collezione` · Chi sono → `/#chi-sono` · Contatti → `/#contatti` · Carrello è già in alto.
- **Pagina Contatti**: nella pagina "Contatti" scegli il modello `contact` per avere anche il modulo.
- **Foto principale**: Personalizza → Foto principale → carica la foto; con i cursori "Posizione della pietra" metti il riflesso sulla pietra.

## Come il tema legge la pietra
Il nome della pietra (titolo delle schede, filtri) viene dalla descrizione del prodotto:
basta scrivere come adesso **"Pietra naturale: Labradorite verde."** (vanno bene anche "Pietre naturali:" e "Pietra:").
Il tipo (collane, bracciali, anelli) viene dalla prima parola del titolo: "Collana…", "Bracciale…", "Anello…".

## Dominio
Impostazioni → Domini → collega un dominio esistente o acquistane uno nuovo.
