# La Culla della Luna

Sito di Alessia Iraci: gioielli con pietre naturali e fili di rame placcati oro e argento.
Un solo file, `index.html`, senza build: aprilo nel browser o pubblicalo su Netlify / GitHub Pages.

## Da completare
- **Instagram / contatti**: sezione `#contatti` in `index.html`, link `https://www.instagram.com/` da sostituire.
- **Pietre**: nomi, colori, tipo di luce (`flash`, `sheen`, `deep`, `veins`, `onyx`) e testi sono nell'array `STONES` dentro lo script.
