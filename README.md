# La Culla della Luna

Sito di Alessia Iraci: gioielli con pietre naturali e fili di rame placcati oro e argento.
Sito statico (nessuna build): apri `index.html`, oppure pubblica la cartella su Netlify / GitHub Pages.

## Da completare
- **Contatti**: in `index.html`, sezione `#contatti`, sostituisci il link Instagram e l'email.
- **Foto**: metti le foto in `images/` e, in `script.js`, sostituisci i segnaposto della galleria (`PIECES`) con `<img src="images/...">`.
- **Pietre**: nomi, colori e testi sono nell'array `STONES` in `script.js`.
